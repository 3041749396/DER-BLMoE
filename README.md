# DER-BLMoE 🚗

Official code for **DER-BLMoE**, proposed in the paper:

> **Robust and Efficient Specific Emitter Identification via Broad Learning-Based Mixture of Experts**  
> Accepted by **IEEE Communications Letters**

DER-BLMoE is a broad-learning-based mixture-of-experts framework for specific emitter identification (SEI). The implementation uses raw ADS-B I/Q samples, computes STFT sub-band features in Python, trains BLS experts for different frequency bands, and fuses expert predictions with a dynamic entropy residual gate.

### Folder and File Roles 🧩

- `configs/`: Global experiment configuration. The main file is `config_moe_bls.py`, which controls dataset paths, number of classes, STFT parameters, PCA dimensions, BLS/MoE hyperparameters, Monte Carlo runs, and deep-learning baseline settings.
- `Datasets/`: Processed dataset folder read by the Python scripts. This folder should contain the `.npy` files generated by `process.mlx`.
- `experiments/`: Runnable experiment scripts for training, testing, SNR robustness, Top-k ablation, and PCA visualization.
- `models/`: Model implementations, including BLS, DER-BLMoE, SFEBLN, ResNet18-1D, and the AJCN adapter.
- `third_party/`: Preserved AJCN source code and a namespaced copy used by `models/ajcn_official_adapter.py`.
- `utils/`: Data loading, STFT feature extraction, energy-boundary cropping, and AWGN noise utilities.
- `process.mlx`: MATLAB preprocessing live script. Run this first to convert the original ADS-B I/Q dataset into the raw real-imaginary concatenated `.npy` format used by the Python code.

## Environment 🛠️

The repository does not include a `requirements.txt`. The following packages are imported by the main Python code:

```bash
pip install numpy scipy scikit-learn pandas matplotlib seaborn tqdm torch pyyaml
```

Use the PyTorch installation command that matches your CUDA version if GPU training is needed. The code automatically uses CUDA when available for ResNet18 and AJCN.

MATLAB is required only for preprocessing with `process.mlx`. The MATLAB script calls `readNPY` and `writeNPY`, so make sure an NPY I/O toolbox such as `npy-matlab` is available on the MATLAB path.

## Data Preparation 📡

Run the MATLAB preprocessing script before running Python experiments.

Expected workflow:

1. Put the original ADS-B `.npy` files under:

```text
source/
```

2. Run `process.mlx` in MATLAB.

3. The processed files will be written to:

```text
Datasets/
```

For the 10-class ADS-B experiment, the Python configuration expects these files by default:

```text
Datasets/X_train_10Class.npy
Datasets/Y_train_10Class.npy
Datasets/X_test_10Class.npy
Datasets/Y_test_10Class.npy
```

Each `X_*.npy` file is expected to use the real-imaginary concatenated raw I/Q format:

```text
[Real_Part, Imag_Part]
```

with shape:

```text
(num_samples, 2 * sequence_length)
```

🤯 Important: the inspected `process.mlx` currently sets:

```matlab
class_list = {'30Class'};
```

For the 10-class dataset, change it to:

```matlab
class_list = {'10Class'};
```

Then place the original files as:

```text
source/X_train_10Class.npy
source/Y_train_10Class.npy
source/X_test_10Class.npy
source/Y_test_10Class.npy
```

✅ After preprocessing, verify that the same four filenames exist under `Datasets/`.

If you want to run a different number of classes, keep the MATLAB output filenames and the Python config synchronized by changing `NUM_CLASSES`, `X_TRAIN_RAW_FILE`, `X_TEST_RAW_FILE`, `Y_TRAIN_FILE`, and `Y_TEST_FILE` in `configs/config_moe_bls.py`.

## Configuration ⚙️

Edit:

```text
configs/config_moe_bls.py
```

Common settings:

- `DATA_ROOT`: processed dataset directory. Default: `Datasets/`.
- `RESULTS_ROOT`: output directory for evaluation results. Default: `compare_results/`.
- `NUM_CLASSES`: number of emitter classes. Default: `10`.
- `NUM_LOGICAL_EXPERTS`: number of STFT sub-bands and logical experts. Default: `5`.
- `USE_PCA`: whether to apply PCA to STFT sub-band features.
- `PCA_DIM_MOE`: PCA dimension per MoE expert. Default: `16`.
- `PCA_DIM_BASELINE`: PCA dimension used by the baseline BLS path.
- `MOE_TOP_K`: number of selected experts during DER-BLMoE inference. Default: `3`.
- `STFT_NPERSEG`, `STFT_NO_OVERLAP`, `STFT_NFFT`: STFT settings.
- `STFT_ENERGY_RATIO`: retained energy ratio for global frequency-bin cropping. Default: `0.95`.
- `INF_BENCH_MC`: number of repeated training runs. Default: `50`.
- `DL_EPOCHS`, `DL_BATCH_SIZE`, `DL_LR`: ResNet18-1D baseline training parameters.
- `AJCN_BASE_EPOCHS`, `AJCN_RL_EPISODES`, `AJCN_FINAL_EPOCHS`: AJCN baseline and compression settings.

🙂 For a quick smoke test, reduce the expensive settings, for example:

```python
INF_BENCH_MC = 1
DL_EPOCHS = 1
AJCN_BASE_EPOCHS = 1
AJCN_RL_EPISODES = 1
AJCN_RL_CANDIDATE_EPOCHS = 1
AJCN_FINAL_EPOCHS = 1
```

🤯 The current training script always trains BLS, SFEBLN, DER-BLMoE, ResNet18, and AJCN. There is no command-line switch in the inspected code for skipping baselines; use the reduced settings above for quick testing.

## Training 🚀

From the repository root, run:

```bash
python experiments/exp_train.py
```

The script will:

1. Load raw I/Q data from `Datasets/`.
2. Compute global STFT energy-cropping bounds from the full training set.
3. Generate STFT features for train and test data.
4. Split the training set into an internal 80/20 train/validation split for deep-learning baselines.
5. Train:
   - BLS baseline
   - SFEBLN baseline
   - DER-BLMoE
   - ResNet18-1D baseline
   - AJCN baseline
6. Save checkpoints under:

```text
checkpoints/<timestamp>_<NUM_CLASSES>Class/
```

Each repeated run is saved as:

```text
checkpoints/<experiment>/run01/
checkpoints/<experiment>/run02/
...
```

Typical saved files include:

```text
pca_transformers_baseline.pkl
pca_transformers_moe.pkl
run_bls_model.pkl
run_sfebln_model.pkl
run_flagship_moe_model.pkl
run_resnet18_best.pth
run_ajcn_best.pth
run_ajcn_info.pkl
training_times.pkl
```

After training, run:

## SNR and Top-k Ablation 🔍

Run:

```bash
python experiments/snr_ablation.py
```

Useful options:

```bash
python experiments/snr_ablation.py --k_values 1,2,4 --snr_values -15,-10,-5,0,5,10,15,20
```

To evaluate a specific checkpoint folder:

```bash
python experiments/snr_ablation.py --exp_dir 2026_7_30_9_07_10Class
```

This script compares:

- Baseline BLS
- DER Top-k settings, such as `k=1`, `k=2`, and `k=4`
- DER-BLMoE with the default `MOE_TOP_K`
- Uniform average of all experts

✅ No retraining is performed for this ablation; `k` is changed only at inference time.

Outputs:


## Reproducing the Main Experiment 🔁

1. Prepare the original ADS-B 10-class files in `source/`.
2. Edit `process.mlx`:

```matlab
class_list = {'10Class'};
```

3. Run `process.mlx` in MATLAB.
4. Confirm that `Datasets/` contains:

```text
X_train_10Class.npy
Y_train_10Class.npy
X_test_10Class.npy
Y_test_10Class.npy
```

5. Check `configs/config_moe_bls.py`:

```python
NUM_CLASSES = 10
NUM_LOGICAL_EXPERTS = 5
USE_PCA = True
PCA_DIM_MOE = 16
MOE_TOP_K = 3
STFT_ENERGY_RATIO = 0.95
```

6. Train:

```bash
python experiments/exp_train.py
```

7. Test:

```bash
python experiments/exp_test_record_95ci_time.py
```

8. Run optional robustness and ablation experiments:

```bash
python experiments/exp_robustness_snr.py
python experiments/snr_ablation.py
python experiments/exp_pca_analysis.py
```

## Notes 💡

- `Datasets/`, `checkpoints/`, and `compare_results/` can become large and are usually excluded from Git.
- The Python code computes STFT features dynamically from the processed raw I/Q arrays; precomputed STFT `.npy` files are not required by the current main pipeline.
- `exp_test_record_95ci_time.py` and `exp_robustness_snr.py` automatically select the latest experiment folder in `checkpoints/`.
- The AJCN baseline uses the official AJCN modules preserved under `third_party/`, with only a raw-I/Q to `32 x 32 x 3` adapter implemented for this project.
